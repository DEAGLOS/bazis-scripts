# UI и визуал вьювера

Читать вместе с `../CLAUDE.md`.

## Тулбар (все подтверждены рабочими)
- Выбор папки целиком (`webkitdirectory` + рекурсивный drag&drop через
  `webkitGetAsEntry`) — указывает всю папку экспорта разом, вложенная
  `<имя_dae>_textures` подхватывается сама.
- "Глобальный свет" (`THREE.HemisphereLight` — не настоящий realtime GI,
  дешёвая имитация рассеянного света) — по умолчанию ВЫКЛ.
- "Контур" (чёрные `EdgesGeometry`-рёбра на каждой панели) — по
  умолчанию ВЫКЛ, независимый toggle.
- "Тени" (на деле направленное затенение key/fill light, НЕ настоящие
  отбрасываемые тени — shadow mapping не включён) — по умолчанию ВКЛ,
  выключение гасит key/fill + поднимает ambient до 1.1 (плоская
  заливка).
- Клик по детали (raycaster, отличаем клик от драга по смещению <5px) —
  переставляет `controls.target` на bbox-центр КЛИКНУТОЙ детали (не
  всей сборки — `Group` в JSON есть, но клик её пока не использует).
  Кнопка "Сбросить вид" — возврат к исходному кадрированию.

## Зеркало — THREE.Reflector (честное 1:1 отражение)
Первая версия (`THREE.CubeCamera`/env-карта, одна камера в центре сцены)
давала эффект "увеличительного стекла" — кубокарта снята из ОДНОЙ точки,
не учитывает реальную позицию/расстояние конкретного зеркала.
**Фикс**: для материала с флагом `face.mirror` (см. `material_config.js`
в `materials.md`) подключён `THREE.Reflector` (r128, jsdelivr,
`examples/js/objects/Reflector.js`) — честный рендер сцены с
"зазеркаленной" камеры через плоскость самого зеркала. Хром остаётся на
кубокарте/env-map (округлые поверхности не так заметно страдают от
приближения по направлению).
`buildMirrorFaces(pts, el)` строит Reflector-плоскости ТОЛЬКО на 2
лицевых гранях (торец — обычная геометрия как у всех панелей); сдвиг
плоскости на 1мм наружу по нормали — иначе z-fighting с обычной
геометрией той же грани под ней.

## Env-карта для хрома/металла — THREE.CubeCamera
После сборки сцены: `WebGLCubeRenderTarget(256)` + `CubeCamera` в центре
bbox всей сцены, один разовый захват (сцена статична после сборки).
Результат назначается `envMap` всем мешам с `material.metalness>0`.
Осознанные упрощения (не чинить без запроса): одна общая камера не
по-объектная, самоотражение не исключается, нет PMREM (резкость
отражения не масштабируется по roughness).

## Исключение из отражений — THREE.Layers
Сетка пола, размерные глифы, проволочные боксы 2D-фурнитуры — на слое
`NON_REFLECTED_LAYER=1` (`.layers.set(1)`, для групп — `.traverse` на
каждый лист, `.layers` не наследуется по иерархии как `.visible`).
Основная камера явно включает слой (`camera.layers.enable(1)`) —
внутренние камеры `Reflector`/`CubeCamera` остаются с дефолтными слоями
(только слой 0 у новой камеры в three.js) и естественно не видят слой 1
— правки самого `Reflector.js` не понадобилось.

## Размерные линии (Size3D)
`buildDimensionGroup(pts, el, lineColorHex)`: `lengthAxis`/`armAxis`/
`thicknessAxis` из `Size` (та же структурная логика, что у панелей) → 2
выносные линии (плечи) + основная линия по дальнему краю + 2
стрелки-уголка + текст. Округление `Value` через `Math.round()`.
Поворот текста на 90° при вертикальной `lengthDir` — через
`sprite.material.rotation` (встроенное свойство
`THREE.SpriteMaterial`), НЕ ручной `ctx.rotate` в canvas (тот резал
символы по краю — причиной было именно ручное вращение внутри canvas,
не отступы).

## Офлайн-версия (без CDN) — план, не реализовано
Пользователь хочет локальную сборку без `<script
src="https://cdn...">`. Три файла нужно скачать вручную и прислать
(three.min.js ~600КБ, OrbitControls.js, ColladaLoader.js — jsdelivr,
версия 0.128.0) — дальше просто склейка на диске. Формат конфига —
`config.js`, НЕ `.txt` (`file://`-режим блокирует `fetch()` в Chrome,
`.js` подключается тегом `<script>` без этого ограничения):
`var LOCAL_MODE = true/false;`.

## Найденные и исправленные UI-баги
- Статистика (`#stats`) была перекрыта тулбаром (тулбар вырос до 5
  кнопок за сессию) — переставлена ниже (`top:52px;right:18px`).
- Настоящая причина, почему статистика не появлялась даже после
  переноса: `display:none` был в CSS-ПРАВИЛЕ (`#stats{...}`), а не
  инлайн в теге, как у остальных панелей (`hud`/`toolbar`/`hint`) — код
  показа `.style.display=''` очищает только ИНЛАЙН-переопределение,
  стилшитное правило это не снимает. Фикс: `.style.display = 'block'`
  явно.
