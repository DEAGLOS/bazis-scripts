# Bazis-Мебельщик — скрипты

Скрипты (JavaScript) для Базис-Мебельщика: расширения функционала,
которых нет в самой программе.

Файлы скриптов — в кодировке CP1251 (требование самого Базиса для
корректной кириллицы в диалогах).

## Инструменты

- **`текст-в-3д/`** — объёмный текст (текст → 3D-модель), с готовыми
  наборами шрифтов (Arial, GostBazis, Times New Roman).
- **`габаритная-рамка/`** — габаритная рамка (`TModelLimits`):
  подгонка под выделение.

Репозиторий начат "с чистого листа" — только новые, готовые скрипты.
Черновики, эксперименты и наработки по другим проектам сюда сознательно
не выкладываются.
